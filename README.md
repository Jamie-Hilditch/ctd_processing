# ctd-processing

A command line application for processing RBR CTD data (`.rsk` files) into
CF-compliant, TEOS-10 derived oceanographic datasets.

```bash
uv add ctd-processing
```

See the [documentation](https://jamie-hilditch.github.io/ctd_processing/)
for installation, configuration, and CLI reference, or
[docs/quickstart.md](docs/quickstart.md) to get started locally.
